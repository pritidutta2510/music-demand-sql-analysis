# MUSIC RETAIL DEMAND MODELLING USING SQL AND POWER BI

# Project Overview
Analysed transactional data from a music retail business to surface demand patterns across genres, geographies and customer segments. 
SQL was used for querying and aggregation; Power BI for interactive KPI visualisation.

# Tools Used
SQL (MySQL)    Excel    Power BI

# Dataset
An 11-table relational dataset covering customers, invoices, tracks, albums, artists, genres, employees and playlists. 
Full schema diagram included in repo.

# Key Analysis
- Genre-based demand trends
- Customer purchasing behaviour
- Sales performance KPIs

# Key Findings
- **Top 5 revenue countries** identified, with the USA accounting for the largest share of sales volume
- **Rock genre dominance** confirmed across purchase frequency and revenue contribution
- Dashboard KPIs: **₹4.71K total revenue** across **4,757 tracks sold**
- Customer behaviour segmentation revealed opportunities for targeted genre-based promotions and inventory planning
- Pricing optimisation recommendations derived from demand concentration patterns

# Dataset Usage
This repository includes a full transactional dataset that can be used for practicing SQL queries and building dashboards.
This dataset is intended for educational use, including SQL practice, analytics training, and interview or placement preparation.
